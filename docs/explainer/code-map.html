01

システム構成

エディターは Electron の2つのプロセス と、子プロセスとして起動する エンジン でできています。データベースはなく、状態はすべてレンダラーの Vuex が持ちます。

📦

配るもの

electron-builder で、Windows は NSIS Web インストーラー、macOS は dmg、Linux は AppImage を作ります（）。

🧑‍💻

手元で動かす

pnpm run electron:serve で Electron 版、pnpm run browser:serve でブラウザ版。.env でエンジンの場所を指定します。

🌐

ブラウザ版

が window.backend を Web API で再現します。e2e テストもこちらで動きます。

👋

ウェルカム画面

03

レイヤー構成

上の段は下の段だけを呼びます。コンポーネントからエンジンや window.backend を直接呼ばない のが約束です。

✍️

関数を足すときは型から

Vuex の型は自前です。まず の 〜StoreTypes に宣言し、対応するストアに実装します。

🗂️

Map や配列は差しかえる

大きい Map・配列はインスタンスごと watch する前提です。更新するときは中身を書きかえず、新しいインスタンスに差しかえます。

⚠️

エラーの出し方

関数側で投げ、画面側でつかまえて表示します。ユーザーに見せる例外は DisplayableError を使います。

05

データの形

トークは AudioItem を、ソングは Track と Note を中心にデータが流れます。

AudioItem：テキスト欄1つ

項目型役目
textstring入力されたテキスト（メモ・ルビ記法を含む）
voiceVoice{ engineId, speakerId, styleId }。声を一意に決める組
queryEditorAudioQuery?エンジンから届いた設計図。まだなければ undefined
presetKeyPresetKey?適用しているプリセット
morphingInfoMorphingInfo?モーフィング相手のスタイルと割合

ストアでは audioKeys（並び順の配列）と audioItems（キー → AudioItem）の2つに分けて持ちます。

AudioQuery・AccentPhrase・Mora

型主な項目役目
AudioQueryaccentPhrases・speedScale・pitchScale・intonationScale・volumeScale・prePhonemeLength・postPhonemeLength・pauseLengthScale・outputSamplingRate・outputStereo・kana音声合成の設計図。エディター側は EditorAudioQuery（サンプリングレートに "engineDefault" を許す）に変換して持つ（）
AccentPhrasemoras・accent・pauseMora?・isInterrogative?アクセント句。accent は 1〜モーラ数。疑問文なら語尾を上げる
Moratext・consonant?・consonantLength?・vowel・vowelLength・pitch1拍。詳細調整欄の「イントネーション」は pitch、「長さ」は consonantLength・vowelLength

Command：Undo の単位

項目型役目
idCommandId保存時に「最後のコマンド」を覚えて、未保存かどうかを判定するのに使う
redoPatchesPatch[]immer の変更パッチ
undoPatchesPatch[]逆向きのパッチ

undoCommands・redoCommands は talk と song で別々のスタックです。

Track・Note：ソング

型主な項目役目
Noteid・position・duration・noteNumber・lyric音符1つ。位置と長さは tick（4分音符 = 480 tick）、高さは MIDI ノート番号。歌詞未入力は null
Trackname・singer?・notes・pitchEditData・volumeEditData・phonemeTimingEditData・solo・mute・gain・pan・keyRangeAdjustment・volumeRangeAdjustmentトラック1本。手で描いたピッチ（Hz）・音量・音素タイミングの編集もここに持つ
Tempo・TimeSignatureposition・bpm ／ measureNumber・beats・beatTypeテンポ（既定 120）と拍子（既定 4/4）の変化点

プロジェクトファイル（.vvproj）

項目中身メモ
appVersion保存したエディターのバージョンマイグレーションの判定に使う（）
talkaudioKeys・audioItemsトークの全テキスト欄
songtpqn・tempos・timeSignatures・tracks・trackOrderファイルでは Map を使えないので、phonemeTimingEditData などはオブジェクトに変換して保存（）

設定（config.json）

Zod のスキーマで定義され、メインプロセスの ConfigManager がユーザーデータフォルダの config.json に保存します。書き出し設定（savingSetting）、キー割り当て（hotkeySettings）、プリセット（presets）、エンジンごとの設定（engineSettings）などが入ります。古い形式は がバージョンごとに変換します。

08

横断的な仕組みの場所

しくみ何をしているかファイル
型つき VuexcreatePartialStore で各ストアを型つきで定義し、index.ts でまとめる

Undo・RedoCOMMAND_ の mutation を immer のパッチで記録
UI ロック・進捗createUILockAction で処理中は操作を止める
エラー表示DisplayableError（ユーザー向けメッセージつき例外）
IPC のエラー受けわたし例外を TransferableResult に包んで、プロセスをまたいでも同じ型で扱う
ID の型EngineId・SpeakerId・StyleId・AudioKey などを区別する型
Result 型成功と失敗を値で返す
ログレンダラーからは window.backend.logError など、メインでは electron-log
モックエンジン本物のエンジンなしで動かすための実装（テスト・ブラウザ版）
エンジン接続の切りかえ製品版 Electron は本物だけ、それ以外はモックも使える
ダイアログを関数で出すshowAlertDialog・showQuestionDialog など
アプリのセキュリティリンクは外部ブラウザ、ナビゲーション禁止、Electron Fuses
